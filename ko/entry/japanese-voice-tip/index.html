피드백/개선요청

한국어판은 첫 실행 시 타이틀 없이 바로 시작되어 기본 음성이 영어입니다. 처음부터 일본어 음성으로 진행하려는 사용자를 위한 보고.

한국어: 임시 표기

타이틀 화면에서 음성을 일본어로 바꾼 뒤 저장 파일을 삭제하고 처음부터 다시 하면 설정도 같이 지워져 다시 영어가 나온다는 보고입니다. 보고된 우회법: Switch 2 기기 언어를 일본어로 바꿔 시작(자막도 일본어)한 뒤 타이틀로 돌아와 기기 언어를 한국어로 되돌립니다. 일본판 데이터를 그대로 써도 진행은 되지만 이스마르 이름에 가나·알파벳만 쓸 수 있어 한글 이름을 원하면 데이터 삭제 후 재시작이 필요합니다.

나무위키 서술 기반 미검증 보고입니다. 발매 직후 게임 시작부터 한국어 자막+일본어 음성을 적용하는 더 간단한 방법이 공유되었다고 하나 링크 내용은 확인하지 않았습니다.
